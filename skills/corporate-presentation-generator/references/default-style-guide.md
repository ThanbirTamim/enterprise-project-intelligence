# Default style guide (original, neutral, placeholder branding)

This is an original, independently written default used only when the user supplies no corporate
guideline of their own. It is intentionally generic and must never be presented as any specific
company's proprietary standard.

## Typography
- Titles: a single clean sans-serif family, one weight for titles, one for body text.
- Title size roughly 2x body text size; keep a consistent scale across the deck (e.g., title 32pt,
  section header 24pt, body 18pt, caption 12pt — adjust proportionally for the chosen tool).
- Avoid more than two font families in one deck.

## Color
- One primary accent color, one neutral dark text color, one light background, one semantic
  "warning/risk" color used consistently for risk callouts. Use placeholder hex values
  (`#2B6CB0` primary, `#1A202C` text, `#FFFFFF` background, `#C53030` risk) that the user should
  replace with their own palette.

## Layout
- Consistent margins on all slides (recommend 6% of slide width/height as a starting margin).
- A visible slide title on every content slide; a page/slide number in a consistent corner.
- No more than ~6 bullet lines per content slide; prefer one key idea per slide over dense text.

## Required sections (adapt per deck purpose)
- Title slide, executive summary, body sections, risks/decisions, references/assumptions, closing.

## Citations
- Every factual claim on a slide should carry a small citation marker resolved in speaker notes or a
  references slide, not asserted bare.

## Speaker notes
- Each slide should have at least one sentence of speaker notes stating the key takeaway and, when
  relevant, its evidence source.

## Human-review flags
- Visual balance, diagram clarity, and brand aesthetic judgment are flagged for human review; this
  guide does not claim to automate taste.
