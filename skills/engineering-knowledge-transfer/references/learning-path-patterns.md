# Learning path patterns

## New engineer onboarding
System purpose → architecture overview → local setup → core workflow walkthrough → codebase tour →
first good-first-task suggestions → where to ask for help.

## Operator runbook
Service overview → normal operating indicators → common alerts and their meaning → step-by-step
response procedures (cited to documented procedure where possible) → escalation path → known
limitations.

## Handover document
Scope of responsibility being handed over → current state and recent changes → open issues/risks →
key contacts/ownership → access and credentials process (never embed actual credentials) → outstanding
decisions.

## Troubleshooting guide
Symptom → likely causes (ranked, cited) → diagnostic steps → resolution steps → when to escalate.
