# Citation format

Cite every material claim using the evidence-index `source_location` format produced by
`project-documentation-discovery`:

- Markdown/HTML heading: `path/to/file.md#heading-slug`
- PDF page: `path/to/file.pdf#page-12`
- PPTX slide: `path/to/file.pptx#slide-7`
- Table/row: `path/to/file.csv#row-42`
- Source code: `path/to/file.ts#L120-L135`

In prose, cite inline like: `Projects can be archived once all milestones close
[source: handbook/lifecycle.md#archiving].` Keep the bracketed citation close to the specific claim
it supports, not only at the end of a paragraph covering several claims.
