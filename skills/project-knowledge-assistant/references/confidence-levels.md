# Confidence levels

| Label | Meaning |
|---|---|
| `documented` | Stated directly in a source document. |
| `verified-in-code` | Confirmed by reading the actual implementation. |
| `inferred` | A reasonable conclusion from combining multiple documented facts; not itself stated anywhere. |
| `unverified-claim` | Reported by a stakeholder/document but not independently confirmed. |
| `superseded` | Once documented but contradicted by a newer source; both are cited, newer is preferred but flagged as a change. |

Always attach one of these labels when a claim is not a direct, single-source `documented` fact.
