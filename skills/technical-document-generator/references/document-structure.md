# Document structure patterns

## Strategy / assessment documents
1. Executive summary
2. Context and evidence base
3. Findings (cited)
4. Recommendations
5. Risks and open questions
6. References

## Roadmap documents
1. Summary
2. Phases (objectives, deliverables, acceptance criteria, exit conditions)
3. Dependencies
4. Risks

## Onboarding / knowledge-transfer documents
1. Overview and audience
2. Prerequisites
3. Core concepts (cited)
4. Step-by-step walkthroughs
5. Troubleshooting
6. Where to get help / further references
